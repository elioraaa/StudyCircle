# StudyCircle

A web platform for UNYT students to find, create and join study groups by course, schedule study sessions and chat with group members.

Software Engineering course project – University of New York Tirana (UNYT).

## Tech Stack
- Frontend: React (Vite)
- Backend: NestJS
- Database: PostgreSQL
- API testing: Postman

## Project Structure
- `frontend/` – React app
- `backend/` – NestJS REST API

## How to Run
```bash
# Backend
cd backend
npm install
npm run start:dev

# Frontend
cd frontend
npm install
npm run dev
```
